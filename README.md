# 🛒 E-Commerce Application

A Java-based e-commerce application currently under development.

The project is being built to gain practical experience with **Java backend development, Maven, application architecture, database integration, and REST-based services**.

## 🚧 Project Status

**Work in Progress**

The application is currently under active development. Features and architecture will continue to evolve as the project progresses.

## 🛠️ Tech Stack

* **Java**
* **Maven**
* **Spring / Spring Boot** *(as implemented)*
* **SQL / Database** *(as implemented)*

## 🎯 Objectives

The main goals of this project are to:

* Build a real-world backend application
* Apply Java and OOP concepts in a practical project
* Understand backend application architecture
* Work with databases and persistence
* Develop and integrate REST APIs
* Learn industry-relevant backend development practices

## 📌 Planned Features

* User authentication and authorization
* Product management
* Product browsing
* Shopping cart
* Order management
* Database integration
* REST APIs
* API validation and error handling

> Features will be added progressively as development continues.
